# 🇷🇺 President Simulator — Полная русская локализация

Русификатор для **President Simulator**, позволяющий играть на русском языке вместо английского.

## 📋 О русификаторе

- ✅ Переведены все **17 доступных таблиц локализации**.
- ✅ Всего переведено **2030 текстовых записей**.
- ✅ Переведены элементы интерфейса, игровые сообщения и другие доступные тексты.
- ✅ Перевод встроен непосредственно в английскую локализацию — в настройках игры необходимо выбрать **English**.
- ✅ Некоторые технические строки, обозначения и значения времени оставлены без изменений для корректной работы игры.

## 📥 Установка

1. Полностью закройте игру.
2. Перейдите в папку игры:

   `PresidentSim_Data\StreamingAssets\aa\StandaloneWindows64`

3. **Создайте резервные копии** оригинальных файлов:
   - `catalog.bin`
   - `localization-string-tables-english(en)_assets_all.bundle`

4. Скачайте архив русификатора из раздела **Releases** и распакуйте его.
5. Скопируйте оба файла из архива в указанную папку игры, подтвердив замену.
6. Запустите **President Simulator**.
7. В настройках языка выберите **English**.

**Важно:** файл `catalog.hash` изменять или заменять не нужно!

## 🔄 Как удалить русификатор

Чтобы вернуть оригинальную английскую локализацию, воспользуйтесь одним из способов:

**Способ 1 — Восстановление из резервной копии**

Замените изменённые файлы `catalog.bin` и `localization-string-tables-english(en)_assets_all.bundle` их оригинальными версиями.

**Способ 2 — Через Steam**

1. Откройте библиотеку Steam.
2. Нажмите правой кнопкой мыши на **President Simulator**.
3. Выберите **Свойства → Установленные файлы**.
4. Нажмите **Проверить целостность файлов игры**.

Steam восстановит оригинальные файлы.

## ⚠️ Важная информация

- Русификатор является **неофициальным фанатским переводом**.
- После обновления игры перевод может перестать работать или потребовать повторной установки.
- Некоторые фразы могут содержать неточности перевода.
- Перед установкой рекомендуется сохранять оригинальные файлы.
